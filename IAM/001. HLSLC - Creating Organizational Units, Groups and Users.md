# HomeLab Simulated Logistic Company (HLSLC)

---

## Creating Organizational Units

Using Powershell:

```
New-ADOrganizationalUnit -Name "HLSLC" -Path "DC=lab,DC=local"
```

<img src="images/IAME001-001.png" alt="IAME001-001" width="70%">

HLSLC is deployed in the root of lab.local, inside this Organizational Unit (OU) the different departments of the company are nested.

```
New-ADOrganizationalUnit -Name "Accounting" -Path "OU=HLSLC,DC=lab,DC=local"
New-ADOrganizationalUnit -Name "Dispatch" -Path "OU=HLSLC,DC=lab,DC=local"
New-ADOrganizationalUnit -Name "IT" -Path "OU=HLSLC,DC=lab,DC=local"
New-ADOrganizationalUnit -Name "Management" -Path "OU=HLSLC,DC=lab,DC=local"
New-ADOrganizationalUnit -Name "Sales" -Path "OU=HLSLC,DC=lab,DC=local"
New-ADOrganizationalUnit -Name "Warehouse" -Path "OU=HLSLC,DC=lab,DC=local"
New-ADOrganizationalUnit -Name "Groups" -Path "OU=HLSLC,DC=lab,DC=local"
```

## Creating Groups

Groups in an Organizational Unit created inside the company's OU in the same level as the department's OU, in this nested OU are created the different groups that will be used to assign rights and privilegies to users according to their role in the company.

```
New-ADGroup -Name "Accounting" -Path "OU=HLSLC,OU=Groups,DC=lab,DC=local"
New-ADGroup -Name "Dispatch" -Path "OU=HLSLC,OU=Groups,DC=lab,DC=local"
New-ADGroup -Name "IT" -Path "OU=HLSLC,OU=Groups,DC=lab,DC=local"
New-ADGroup -Name "Management" -Path "OU=HLSLC,OU=Groups,DC=lab,DC=local"
New-ADGroup -Name "Sales" -Path "OU=HLSLC,OU=Groups,DC=lab,DC=local"
New-ADGroup -Name "Warehouse" -Path "OU=HLSLC,OU=Groups,DC=lab,DC=local"
New-ADGroup -Name "Warehouse-Seasonal" -Path "OU=HLSLC,OU=Groups,DC=lab,DC=local"
New-ADGroup -Name "Finance-Data-Access" -Path "OU=HLSLC,OU=Groups,DC=lab,DC=local"
New-ADGroup -Name "Helpdesk" -Path "OU=HLSLC,OU=Groups,DC=lab,DC=local"
```
